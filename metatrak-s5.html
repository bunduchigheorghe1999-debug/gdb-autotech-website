Meta Trak S5 & S5 Deadlock

Category S5 insurance-approved tracking with driver recognition, app monitoring and optional immobilisation through S5 Deadlock.

Meta Trak S5

  • Category S5 insurance-approved tracking.
  • Driver recognition using an ID tag.
  • Vehicle usage tracking through the mobile app.
  • 24/7 stolen-vehicle support.
  • Designed for discreet, covert vehicle security.

S5 Deadlock

  • Adds immobilisation to the S5 tracking system.
  • No-tag, no-start functionality can prevent the vehicle from being started without the authorised ID tag.
  • Deadlock commands can be used to block engine starting remotely.
  • OBD-port immobilisation can help prevent unauthorised key programming when configured for the vehicle.

Important for customers

  • S5 and S5 Deadlock are different configurations; GDB Autotech can explain which option suits your vehicle.
  • Insurance requirements vary, so confirm your insurer's required category before booking.
